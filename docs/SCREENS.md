# Espresso 화면 설계 (태블릿·노트북 우선)

- 웹: React (관리자·물류 페이지), 앱: React Native(Expo) — 같은 디자인 토큰·컴포넌트 규칙 공유
- 기준 해상도: **노트북 1440×900**, **태블릿 가로 1180×820(iPad Air) / 1280×800(갤럭시탭)**, 모바일 390×844
- 금액 표기: 우측 정렬, 천 단위 콤마, VAT 모드 배지 `[VAT 별도]` / `[VAT 포함]`, 면세는 세액 `0 (면세)`
