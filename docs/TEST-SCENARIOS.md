# 계정별 테스트 시나리오

웹: `http://<서버>:18080` · 로그인 화면의 계정 버튼을 누르면 바로 로그인됩니다. 비밀번호는 모두 `demo1234`이며 데모 전용입니다.
자동 점검: `python3 tests/smoke_test.py` (61개 항목) · DB 2중화 확인: `bash tests/check_replication.sh`
새로 띄운 직후라면 먼저 `python3 tests/wait_ready.py`로 데모 데이터 준비를 기다리세요. GitHub에서는 PR·푸시마다 자동 실행됩니다(Actions › smoke-test).

화면 크기를 바꿔 보세요: 노트북(1280px 이상) 사이드 메뉴 / 태블릿(768~1279px) 아이콘 메뉴 / 모바일(767px 이하) 하단 탭.

## 1. 총괄 관리자 `admin`

| # | 할 일 | 확인할 것 |
|---|---|---|
| 1 | 조직도 → 실제 조직 / 등급 구조 | 본사 라인(물류·인적·슈퍼바이저 비활성)과 권역별 매장 인원 |
| 2 | 설정 › 계정·등급 → 계정 만들기, 등급 배정·해제, VAT 표시 지정 | 지정한 계정은 다음 로그인부터 상단 VAT 배지가 바뀜 |
| 3 | 설정 › 매장 관리 → 홍대점 "점주 개인별 급여 열람" 켜기 | owner1 로 홍대점 급여를 열면 개인별로 보임 |
| 4 | 설정 › 매장 관리 → + 매장 생성 → 8단계 진행 → 완료 | 매장 "운영", 초도 물류 요청 자동 생성, 조직도·투자에 반영 |
| 5 | 결재함 → 진행 중 전체 | 다른 사람 차례 문서도 "총괄 직권"으로 승인 가능 |
| 6 | 결산 → 강남점·이번 달 → 월 마감 | 로열티·감가상각 반영, "마감" 표시, 정산서 발행 대기에 로열티 |
| 7 | 본사 정산서 → 정산서 발행 → 입금 확인 | 부분 입금/완납/연체, 확인 시각·확인자 기록 |
| 8 | 세무 → 전표 내려받기 | 엑셀에서 열리는 CSV (일자·차대·계정코드·외부코드·금액·적요) |
| 9 | 매장 비교 → 지표 이름 클릭 | 정렬·순위표, 평균 ±1σ 초록/빨강 강조, 권역 필터 |
| 10 | 투자 관리 → 매장 선택 → 투자자 공개 설정 | 총액/지정액/비율, 결산·회수율 공개 여부 |
| 11 | 설정 › 리포트 노출 → 체크 변경 | 해당 등급의 리포트 섹션이 바로 바뀜 |
| 12 | 설정 › 결재선 → + 결재선 (예: 물류 10만원 미만 물류관리자만) | 그 금액대 요청은 축약 결재선으로 진행 |
| 13 | 설정 › 품목·단가 → [식기·포장] 필터 → [비품 기준] | 식기 기준 100,000원. 바꾸면 해당 품목의 '비품' 표시가 바로 바뀜 |

## 권장 순서 (한 번에 전체 흐름 보기)

1. `mgr1` 물류 요청(본사 + 외부 URL, 본사 결제) 상신
2. `owner1` → `logi` → `admin` 결재함에서 승인
3. `logi` 외부 구매 완료 → 발송 등록
4. `staff1` 수령 검수(수량 하나 줄이기) → `mgr1` 결손 초안에 사진 첨부 후 상신 → 순차 승인
5. `mgr1` 이번 달 매출 마감, 공과금 상신 → 승인
6. `hr` 이번 달 급여 계산 → 상신 → `owner1`·`admin` 승인 → 명세서 발행 → `staff1` 확인
7. `admin` 결산 월 마감 → 정산서 발행 → `owner1` 입금 등록 → `admin` 입금 확인
8. `owner1` 리포트 발행 → `logi`·`hr`·`staff1`로 같은 리포트 열어 섹션 차이 확인
9. `admin` 매장 비교·투자 관리 → `investor1` 투자 현황

## 알려진 제한 (데모)

- 모바일 앱(React Native)은 아직 만들지 않았습니다. 같은 웹을 휴대폰 크기로 열면 하단 탭 화면이 됩니다.
- 판매 시 재고 자동 차감(레시피)은 4차 범위입니다. 그 전까지 월말 실사의 "판매 소진"이 매출원가를 만듭니다.
- 급여 요율·최저임금은 데모 값, 소득세는 간이세액표 미등록 시 추정치입니다.
- 전자세금계산서는 발행 대행사 미연동 상태라 대기열 + 승인번호 수기 입력입니다.
- PDF는 브라우저 인쇄로 저장합니다(서버 PDF 보관 미구현).
- 마감한 달에 나중에 생긴 거래(예: 마감 후 확정한 급여)는 다음 달 조정분으로 들어갑니다.
- 비품 폐기는 결재 없이 점주·총괄이 바로 처리합니다(분개·폐기 사유·처리자 기록). 결재가 필요하면 알려주세요.
